# 序列记忆游戏

一个基于网页的记忆力训练游戏，帮助用户提升工作记忆和持续性注意力。

## 功能特点

- 三个难度等级（简单、一般、困难）
- 渐进式的难度设计
- 实时反馈和动画效果
- 计分系统和最高分记录
- 提示功能
- 生命值系统
- 响应式设计，支持移动设备

## 如何运行

1. 克隆或下载本项目到本地
2. 使用现代浏览器（Chrome、Firefox、Safari等）直接打开 `index.html` 文件
3. 或者使用本地服务器运行（推荐）：
   ```bash
   # 使用 Python 启动简单的 HTTP 服务器
   python -m http.server 8000
   # 或使用 Node.js 的 http-server
   npx http-server
   ```

## 游戏玩法

1. 选择难度等级（简单/一般/困难）
2. 点击"开始游戏"按钮
3. 观察并记住数字闪烁的顺序
4. 按照相同顺序点击数字
5. 正确完成序列后进入下一轮
6. 出错时会消耗生命值
7. 需要帮助时可以使用提示功能（每局3次）

## 难度说明

### 简单模式
- 6个数字序列
- 数字显示时间较长（1.5秒）
- 数字范围：1-6
- 2×3网格布局
- 5条生命值

### 一般模式
- 9个数字序列
- 数字显示时间适中（1秒）
- 数字范围：1-9
- 3×3网格布局
- 3条生命值
- 轻微干扰效果

### 困难模式
- 12个数字序列
- 数字显示时间短（0.8秒）
- 数字范围：1-9
- 3×3网格布局
- 1条生命值
- 多重干扰效果
